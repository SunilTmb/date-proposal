# Date proposal 🌸

Mobile-first interactive date proposal. Plain HTML + CSS + JS, no build step.

## Files
- `index.html`, `style.css`, `script.js`
- `assets/avatar.svg` (replace with your own photo; update the `src` in card 1 if the file name changes)

## Before sharing
Open `script.js` and fill `RESPONSE` near the top:
- `WEB3FORMS_KEY` for automatic email of her answers (free key at web3forms.com)
- `WHATSAPP_NUMBER` (country code + number, digits only) for the "Send my answers" button

## Deploy (free)
- Netlify Drop: drag this folder onto https://app.netlify.com/drop
- GitHub Pages: push to GitHub, then Settings > Pages > Deploy from branch `main` / root
